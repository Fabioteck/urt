# U.R.T. | UNDERGROUND REMIND TEK

Sito web ufficiale del collettivo U.R.T. (Underground Remind Tek).

## Descrizione
U.R.T. è un collettivo di musicisti, producer, DJ e tecnici del suono. Costruiamo frequenze essenziali, architetture ritmiche pure e paesaggi sonori oltre il confine.

## Tecnologie
- HTML5
- Vanilla CSS
- Vanilla JavaScript

## Struttura
- `index.html`: File principale del sito.
- `css/styles.css`: Foglio di stile principale.
- `js/scripts.js`: Script per funzionalità dinamiche (menu mobile, animazioni, etc.).
- `img/`: Risorse grafiche.
